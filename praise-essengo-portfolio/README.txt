# Praise Essengo — Personal Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive styling and light/dark themes
- `script.js` — mobile menu, theme switch, contact email and scroll effects
- `assets/` — place your CV PDF and optional images here

## Before publishing: personalize these items
1. Your contact email is already set to `essengopraise05@gmail.com` in `script.js`.
2. In `index.html`, replace the sample education details with your institution, dates and accurate qualification status.
3. Replace the starter project ideas with real projects. Do not present sample ideas as completed work.
4. Add your real LinkedIn profile URL in the hero social links. You supplied the GitHub display name `Praise Essengo`; replace the generic GitHub link in `index.html` with your exact GitHub profile URL/username when available (GitHub usernames do not contain spaces).
5. Add your work experience, attachment details, certificates and achievements if applicable.
6. Add a CV PDF in `assets/` and create a link/button to it if you want visitors to download it.
7. If you add a profile photo, put it in `assets/` and add an `<img>` element in the hero section.

## Preview locally
Double-click `index.html` to open it in a browser. For a better development workflow, use Visual Studio Code and its Live Server extension.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a **public** repository named `praise-essengo-portfolio` (or another name you prefer).
3. Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for deployment. The site URL will normally be `https://YOUR-GITHUB-USERNAME.github.io/praise-essengo-portfolio/`.
8. Revisit the Pages settings if you need to find the published URL. Changes pushed to the selected branch will be published.

For a personal URL without the repository path, create a repository named exactly `YOUR-GITHUB-USERNAME.github.io` instead. GitHub Pages is a static host; this portfolio's contact form opens the visitor's email application and does not process/store messages on a server.

## Privacy
Only publish information you are comfortable making public. Avoid posting private addresses, ID numbers, personal documents or other sensitive information.


## Photo gallery
The website includes a responsive photo gallery and portrait slot. Add your own JPG photos to `assets/` with these exact names: `profile.jpg`, `campus.jpg`, `project.jpg`, and `events.jpg`. The page shows sample online fallback images until you add your own. Replace these with genuine photos before presenting the site as your personal story.

## Online availability
This is a responsive static website. Once deployed to GitHub Pages, anyone with the published URL can access it online. Updates appear after you upload/commit changed files and GitHub Pages completes deployment. It does not include a database, live visitor analytics, or server-side message storage. The contact form opens the visitor's email application.
